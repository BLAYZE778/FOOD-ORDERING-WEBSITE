# YOUR_WISH - Food Delivery Website

A small website for a food delivery shop, made with HTML, CSS and JavaScript.
Customers can look at the menu, fill in their details, pick a food item and
see the total price before placing the order.

## Files

- index.html - the page structure (menu table and order form)
- style.css - colors and styling
- script.js - calculates the total and checks the form

## How to run

1. Download or copy all three files into the same folder.
2. Open index.html in any web browser (double click it).

No installation is needed.

## What I learned

- Making tables and forms in HTML
- Styling with CSS
- Using JavaScript to read form values and do calculations
